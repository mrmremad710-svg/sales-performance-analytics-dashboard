#  Adidas US Interactive Sales Dashboard

## Project Overview

This project is an Excel-based Sales Performance Dashboard designed to analyze sales data and present key business insights through Pivot Tables, Pivot Charts, interactive Slicers, Timeline, and different types of charts.

The dashboard allows users to explore sales performance across different categories, regions, store types, products, and time periods.

## Data Analysis

The project uses the following fields from the dataset:

- Order_Date
- Product_Name
- Category
- Region
- Store_Type
- Revenue
- Profit
- Units_Sold

`Units_Sold` was used to calculate the total quantity sold.

---

## Pivot Tables

Pivot Tables were created to summarize and analyze the sales data.

The main values used in the Pivot Tables include:

- Revenue
- Profit
- Units_Sold

Excel was used to calculate the Sum of these values.

---

## Interactive Filters

### Category Slicer

A Slicer was created for `Category` to allow interactive filtering of the dashboard by product category.

### Region Slicer

A Slicer was created for `Region` to allow interactive filtering by region.

### Timeline

A Timeline was created using `Order_Date` to analyze and filter the data over different time periods.

The Slicers and Timeline were connected to multiple Pivot Tables and Pivot Charts so that the dashboard updates interactively when filters are changed.

---

## Charts and Visualizations

### 1. Monthly Sales Trend

A Line Chart was created to show the sales trend over time using Revenue.

### 2. Sales by Store Type

A Pie Chart was created to visualize sales distribution by Store Type.

### 3. Top 10 Products by Profit

A Top 10 analysis was created using `Product_Name` and `Profit`, with products ranked according to their profit.

### 4. Profit by Region

A chart was created to analyze Profit across different Regions.

### 5. Revenue by Category

A chart was created to analyze Revenue across different Categories.

### 6. Revenue vs Profit

A Combo Chart was created to compare Revenue and Profit in the same visualization.

---

## Dashboard

A dashboard was created to bring the different analyses and charts together in one place.

The dashboard includes:

- Main project title
- Section and chart titles
- Pivot Charts
- Interactive Slicers
- Timeline
- Merged Cells for layout and design
- Adjusted text alignment
- Adjusted chart sizes and positions
- General visual formatting

---

## Interactivity

The dashboard was tested using:

- Category Slicer
- Region Slicer
- Timeline

Changing the selected Category, Region, or time period updates the connected Pivot Tables and Charts, making it possible to observe how sales performance changes across different selections and periods.
